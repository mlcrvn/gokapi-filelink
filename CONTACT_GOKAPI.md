# Message au mainteneur de Gokapi

## Version anglaise proposée

**Subject: Independent Thunderbird FileLink extension for Gokapi**

Hello,

I’m preparing an independent open-source Thunderbird extension named **FileLink for Gokapi**. It uses Gokapi’s public REST API so Thunderbird users can upload large email attachments to their own configurable Gokapi instance and insert the resulting download link into their messages.

The extension does not include or copy Gokapi source code, and it uses its own custom link-shaped icon rather than the official Gokapi logo. Its settings page references the official repository: <https://github.com/Forceu/Gokapi>. The FileLink block inserted into emails contains no promotional “Learn more” link.

I plan to publish the source code here: <https://github.com/mlcrvn/gokapi-filelink>, and later submit the extension to addons.thunderbird.net. The listing will clearly state that this is an independent community project, not affiliated with or endorsed by Gokapi.

I wanted to let you know before publication and ask whether you have any concern about the name, attribution, or integration approach. I would also be happy to follow any project preference you may have for third-party integrations.

Best regards,

Mathieu Lécrivain

## Traduction française

**Objet : Extension Thunderbird FileLink indépendante pour Gokapi**

Bonjour,

Je prépare une extension Thunderbird open source et indépendante nommée **FileLink for Gokapi**. Elle utilise l’API REST publique de Gokapi afin que les utilisateurs de Thunderbird puissent envoyer les pièces jointes volumineuses vers leur propre instance Gokapi configurable, puis insérer le lien de téléchargement obtenu dans leurs messages.

L’extension ne reprend aucun code source de Gokapi et utilise une icône personnalisée en forme de lien plutôt que le logo officiel de Gokapi. Sa page de paramètres référence le dépôt officiel : <https://github.com/Forceu/Gokapi>. Le bloc FileLink inséré dans les courriels ne contient aucun lien promotionnel « En savoir plus ».

Je prévois de publier le code source ici : <https://github.com/mlcrvn/gokapi-filelink>, puis de proposer l’extension sur addons.thunderbird.net. La fiche précisera clairement qu’il s’agit d’un projet communautaire indépendant, sans affiliation ni approbation de Gokapi.

Je souhaitais vous en informer avant la publication et savoir si vous aviez une objection concernant le nom, l’attribution ou la méthode d’intégration. Je suivrai volontiers toute préférence du projet concernant les intégrations tierces.

Bien cordialement,

Mathieu Lécrivain
